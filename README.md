# EasyPills Learning Studio · web

Sitio estático de [www.easypills.studio](https://www.easypills.studio), publicado con GitHub Pages desde la rama `main`.

- `index.html`: la página (una sola, en español)
- `css/styles.css`, `js/main.js`: estilos e interacciones, sin dependencias
- `assets/`: imágenes, vídeo y tipografías (alojadas aquí, sin Google Fonts)
- `CNAME`: dominio propio para GitHub Pages

Para actualizar la web basta con subir los archivos cambiados a `main`.
